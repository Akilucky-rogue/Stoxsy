# Start here

1. Read `README.md` (what it is and how to run it), then `design/SYSTEM_FLOW.md` (how data moves) and `design/PLATFORM_ROADMAP.md` (where it is going and what the owner has decided).
2. Daily health: `stoxsy doctor`. If something is red, `runbooks/daily_operations.md` says what to do.
3. Each day the Kite session lapses at 06:00: `stoxsy kite login` if you want live minute prices.
4. About once a month: `stoxsy fetch-ter` (AMFI expense ratios). See `runbooks/amfi_ter.md`.
5. When you trade or change holdings: `runbooks/broker_file_import.md`.
6. Changing code? Read `CLAUDE.md` first: real data only, raw first, no orders, public repository.
